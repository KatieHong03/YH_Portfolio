🌟 YUTING (KATIE) HONG - IDEA GALAXY PHOTO ASSET DIRECTORY
========================================================================

Welcome! This folder (`/public/assets/`) is the dedicated directory for your
portfolio assets, background images, and individual project star photos.

Because this project is built with Vite, any file placed in this folder is 
made available at the root URL path. For example, a file saved here as
`galaxy_bg.jpg` can be referenced as `/assets/galaxy_bg.jpg` in your code.

🛠 HOW TO UPLOAD YOUR ASSETS
------------------------------------------------------------------------
You can upload files directly through your file explorer inside the 
AI Studio code editor:
1. Locate the `public` folder at the root directory.
2. Expand it to find the `assets` folder.
3. Right-click or drag-and-drop your image files directly into this `assets` 
   folder, naming them exactly as shown above.

Your images will automatically load and style beautiful round stars and
constellation points immediately on the next refresh!
